# 🎯 Ayanokoji System - Progression Tracker

A Solo Leveling-inspired progression tracking system to build the perfect self across multiple domains.

## 🚀 Features

### Core Features
- **Multi-Domain Progression**: Track progress in ethical hacking, fullstack development, fitness, reading, math, chess, and more
- **Daily Quests**: Fixed daily tasks to complete
- **Skill Evaluation**: Regular assessments to measure your growth
- **Penalty System**: Consequences for missed tasks to maintain discipline
- **Level System**: 0-100% progression with experience points
- **Statistics Dashboard**: Visual representation of your evolution

### 🆕 New Features (v2.0)
- **🏆 Achievement System**: Unlock rewards by completing milestones
- **🎯 Personal Goals**: Set and track custom objectives with deadlines
- **⏱️ Pomodoro Timer**: Focus sessions with time tracking
- **📔 Daily Journal**: Reflect on your day and track mood
- **👑 Rank System**: Solo Leveling-style ranking (E to SSS)
- **📊 Progress History**: Visualize your evolution over time with charts
- **💾 Data Export**: Backup all your progress data

## 🎮 Domains

1. **Ethical Hacking** - Security & penetration testing
2. **Fullstack Development** - Web development mastery
3. **Fitness** - Physical training and bodybuilding
4. **Reading** - Knowledge acquisition
5. **Mathematics** - Problem-solving skills
6. **Chess** - Strategic thinking
7. **Soft Skills** - Communication and leadership

## 📦 Installation

```bash
# Install all dependencies
npm run install-all

# Start the application
npm run dev
```

## 🎯 Usage

1. Access the application at `http://localhost:5173`
2. Create your daily tasks
3. Complete quests to gain XP
4. Track your progression across all domains
5. Level up and unlock new challenges

## 🛠️ Tech Stack

- **Frontend**: React, TailwindCSS, Lucide Icons
- **Backend**: Node.js, Express
- **Database**: SQLite
- **State Management**: React Context API

## 📈 Progression System

- Complete tasks → Gain XP
- Miss tasks → Penalty (XP reduction)
- Reach milestones → Unlock achievements
- Track statistics → Identify areas for improvement
